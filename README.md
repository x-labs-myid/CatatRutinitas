# CatatRutinitas
CatatRutinitas adalah teman setia yang mendampingimu membentuk rutinitas baru yang positif, hingga menjadi bagian alami dari harimu.

# BUILD compatible with Java 17

```bash
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot"
```
```bash
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
```
```bash
java -version
```
